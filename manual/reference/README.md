# Reference

Interfaces of the public classes and functions of LaserCAD, generated from the code.

- [Geometry, rays and beams](geometry_rays_beams.md): Basic objects: everything with a position and a direction, single rays and bundles of rays.
- [Optical elements](optical_elements.md): Elements that change the rays: mirrors, lenses, gratings, beam splitters and more.
- [Compositions and resonators](compositions.md): Containers that place elements on an optical axis and compute the beams.
- [Mounts and components](mounts_components.md): Mounts, posts and the base class for shaped components.
- [Non-interacting components](non_interacting.md): Components that are drawn but do not change the rays.
- [Ready-made modules](modules.md): Functions and classes that build complete assemblies (telescopes, compressors, amplifiers, ...).

For the ideas behind the classes see the discussion in `manual/docs`.
